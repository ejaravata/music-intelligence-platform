# CIS 5500 Project

Welcome to Hotify! Here are list of instructions in order to connect to our server.

1. Clone the repository in command prompt
- Enter into CIS5500 Folder
- From here you should view the server and client folders

2. NPM downlaods in server and client folders. Run the followinfg comands in this order. *Note-you only need to do this step once for each folder
```
cd server
npm start
```

3. Open command prompt
The commands to run once you are in CIS5500 Project Folder:
```
cd server
npm start
```

4. Open new command prompt window
The commands to run once you are in CIS5500 Project Folder:
```
cd client
npm run dev
```
